# uppsala-fantasy-league

Ligatidningen för Uppsala Fantasy League (Yahoo NBA, league 79469). Innehåll och verktyg för journalisten, och på sikt webbplatsen på uppsalafantasyleague.se.

- Artiklar skrivs med skillen `ufl-reporter` (`.claude/skills/ufl-reporter/`). Följ dess röst och struktur.
- Repot är publikt. Lägg aldrig in lösenord, tokens, e-postadresser eller annat som inte ska synas.
- Artiklar committas som `status: utkast` och publiceras först när Max sagt ja.
- Att göra-listan ligger i GitHub Issues.
- Inga tankstreck i AI-genererad text.
- Repot ska fungera i Claude Code i molnet: allt journalisten behöver ligger här, inget läses från `~/Documents` eller valvet.
